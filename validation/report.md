# Validation against Correlates of War and UCDP/PRIO

Snapshot: `2026-10-14` (retrieved 2026-10-14T15:34:10+00:00). Generated by `scripts/validate.py`.

HistWarDB has no battle-death threshold; COW requires 1,000 battle deaths per war and UCDP 25 per year. Agreement is therefore expected to be partial in both directions. "Not in reference" counts HistWarDB war-years that the reference does not code; they are not necessarily errors.

## Crosswalk coverage

227 of 445 HistWarDB states have a COW code (232 a Gleditsch-Ward code). The others are mostly entities that were never members of the interstate system (colonies, protectorates, sub-national or pre-1816 states). Only states with a code enter the comparisons below.
